# templates/

Optional: drop `.pptx`/`.potx` template files here if you'd rather have Deck Architect fill in an
existing branded template (via the base `pptx` skill's template-editing workflow — unzip, edit
`ppt/slides/slideN.xml`, re-zip) instead of generating layouts from scratch with
`scripts/deck_engine.js`. Empty by default; the generative path does not require anything here.
